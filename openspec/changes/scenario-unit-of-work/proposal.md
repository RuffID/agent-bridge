# Короткие сценарные Unit of Work

Этап 10 реализует существующие Application write ports через базовые репозитории и общий технический scope EFCoreLibrary. Read ports остаются отдельными. Сеть, инструменты, оркестрация, migrations и startup не входят в изменение.

Домен получает валидирующее восстановление сохранённого состояния и операцию принятия промежуточных данных обращения. Сохраняемый write token проверяется отдельно от локального доменного snapshot.
