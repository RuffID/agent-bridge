# Адаптация зависимостей

EFCoreLibrary 0.0.9 больше не содержит MaintenanceExecutionMode. Режим с единственным исполнителем остаётся обязанностью приложения: оно останавливает другие экземпляры, writes и DDL перед обслуживанием. Собственный дубликат удалённого enum не вводится.

Пример текущего вызова: `services.AddAgentBridgeDatabaseMaintenance(configuration.GetSection("Backup"));`. Обе старые перегрузки с аргументом режима заменены; потребителям нужна пересборка.

SQL Server maintenance также требует ProjectName для имени backup. Адаптер передаёт стабильное имя `AgentBridge`; серверный каталог и retention остаются настройками приложения. Имя файла формирует EFCoreLibrary, например `backup_AgentBridge_06.11.2026_120000000.bak`.

Проверки регистрации разрешают реальные DI/provider-типы на закрытых соединениях. Они не подтверждают выполнение backup/migrations на сервере. Подготовка DLL-поставки выполняется только после отдельного разрешения скрипта.
