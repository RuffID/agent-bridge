# Только PostgreSQL

## Why

Пользователь выбрал PostgreSQL единственной поддерживаемой БД AgentBridge. SQLite и SQL Server усложняют конфигурацию, тестовую матрицу и поставку. Snapshot PostgreSQL размещён в лишнем дереве папок.

## What Changes

- Удалить адаптеры, миграции, зависимости и сценарии SQLite/SQL Server из AgentBridge.
- Сохранить PostgreSQL API, числовое значение PostgreSql=1 и историю миграций; перенести snapshot в Migrations без изменения содержимого.
- Перенести ограниченную загрузку истории в PostgreSQL, обновить тесты, примеры и сборку комплектов.
- Обновить действующий контракт и документацию; соседние библиотеки и приложения не менять.

## Impact

Breaking change: потребители SQLite/SQL Server должны выбрать PostgreSQL и пересобраться. Перенос данных не входит в задачу. Базы данных и готовые бинарные комплекты не изменяются.
