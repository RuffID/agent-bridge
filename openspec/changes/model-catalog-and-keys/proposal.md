# Каталог моделей и ключ доступа

Этап 13 подключает `/v1/models` через текущую HttpClientLibrary. Индивидуальный ключ предоставляет приложение; только отсутствие (`null`) разрешает общий ключ из CodexLbOptions. Ошибки не запускают повтор с другим ключом.

Независимые Application-порты возвращают снимок возможностей и выбранных модельных настроек. Проверяются точные model/effort и сумма порога сжатия с запасом против объявленного input_context_window. Каталог читается для выбранного ключа без статического списка и общего кеша. Responses, tokenizer, compact и управление настройками этапа 21 не реализуются.
