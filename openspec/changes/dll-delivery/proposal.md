# Поставка DLL — этап24

## Причина

Сборка из исходников с ProjectReference не подтверждает возможность подключения автономного бинарного комплекта. После принятого этапа23 требуется отдельная проверка состава и compile-only потребителя .NET10.

## Изменения

- Подготовить локальные комплекты SQLite/PostgreSQL для win-x64 через стандартный SDK Build, без pack/publish и executable hooks.
- Сохранить полную runtime closure общего EF-адаптера, выбранную migrations assembly, tokenizer data и XML-документацию.
- Проверить бинарные ссылки вне дерева исходников и доступность XML/наследуемых контрактов через metadata.
- Описать состав, конфигурацию, внешние требования и границы подтверждений.

## Границы

Production API, схема, поведение агента и соседние библиотеки не меняются. Приложение, native engine, HTTP, БД и dump-процессы не запускаются. Этап25 и commit требуют отдельного поручения. OpenSpec CLI проверяется без установки; недоступность не заменяется заявлением о validation.
