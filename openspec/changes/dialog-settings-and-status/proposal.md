# Настройки и статус диалога

## Причина

Этап21 предоставляет безопасное управление моделью/effort и статус жизненного цикла через API библиотеки. Существующий reader проверяет выбор, но не сохраняет его.

## Изменения

- Сохранять выбор модели/effort в БД AgentBridge для конкретного диалога.
- Проверять выбор динамическим каталогом и фиксировать его на выполняющееся обращение.
- Возвращать безопасные лимиты, срок, объём содержимого, размер контекста, число compact и отдельную фактическую модель сервера.
- Передавать явные предупреждения/отказы без удаления истории и секретов.

## Граница

Только этап21. Сценарии удаления/очистки22 и внешний пример23 не реализуются. Generated migrations создаются только штатным tooling после согласования точных команд.
