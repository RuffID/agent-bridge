## Назначение

Компактный результат становится новым рабочим окном только через отдельную границу сохранения. Транспорт сам не меняет диалог и не удаляет историю.

## Проверенный внешний контракт

Локальные codex-lb app/core/openai/v1_requests.py, requests.py и models.py проверены 2026-10-04. CompactResponsePayload допускает discriminator, начинающийся с response.compact, и отсутствие status. Поэтому обычный ResponseJsonReader не подтверждает успешный compact корректно.

## Continuation и ограничения

Компактный id не объявлен generation previous_response_id. Результат хранит полный envelope, но не создаёт continuation. Вход с continuation отклоняется до HTTP. Tools/text/tool_choice сервер compact удаляет; адаптер не обещает их применение и явно отклоняет неподдержанный вход.

## Пример

Ответ {"object":"response.compaction","id":"cmp_1","output":[{"type":"compaction","encrypted_content":"opaque"}]} имеет Completed lifecycle без status. Его единственный input item — объект из output, envelope/id не добавляются в input. Unknown поля сохраняются без раскрытия opaque.

## Принятые прикладные решения

Пользователь согласовал сжатие только активного окна и следующего непрерывного terminal prefix. Provider items, InProgress tail и новый несохранённый input учитываются в полном trigger/budget, но не входят в сохраняемое окно. Вклады провайдеров фиксируются один раз на вызов. Tools/controls остаются в полном generation request; compact получает отдельную проекцию.

Пользователь согласовал сохранение валидного Completed окна при неизвестной полной оценке: результат UnknownBudget немедленно останавливает проходы и не разрешает генерацию. Guard17 остаётся обязательной отдельной проверкой. Успешно сохранённый первый проход остаётся актуальным при отказе второго; stale/expired/ошибка не принимают новый кандидат. Время перед SaveAsync читается заново через TimeProvider, token берётся только из исходного read либо успешного save.

## Ошибки и проверка

Explicit error/failed имеет приоритет; неизвестный status не подтверждает завершение. Fake handler/local streams проверяют адаптер, но не live compatibility. Без обычной генерации-резюме, retry, смены ключа либо модели.
