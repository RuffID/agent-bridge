# Руководство потребителя и закрытие первоначального плана

## Причина

Поставка24 предоставляет автономные DLL, но проверенный consumer пока не показывает создание диалога и полный поток публичных сценариев. Устойчивые документы содержат исторические заявления о ещё не реализованных этапах.

## Изменение

Подготовить короткий README, руководство с проверяемыми исходниками compile-only consumer, фактическую карту API/обязанностей приложения и evidence00–25. Скомпилировать внешнюю копию примеров с обоими существующими комплектами24. Синхронизировать нормативные требования и контекст, актуализировать только устаревшие текущие утверждения.

## Границы

Production API, схема, generated migrations и готовые artifacts не меняются. Методы примеров не исполняются. При отсутствии OpenSpec CLI явно оставить validation невыполненной и change не архивировать. Приёмка и локальный коммит — отдельные шаги координатора.
