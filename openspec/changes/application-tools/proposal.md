# Инструменты приложения — этап 19

## Причина

IToolHandler существует, но регистрации и ограниченного исполнения canonical function calls нет.

## Изменения

Добавить registry описаний/schema и scoped handlers, обязательную проверку аргументов/прав приложения, сессию с фиксированной принадлежностью и ограничениями времени/шагов/параллельности, canonical outputs и сохранение частичного отчёта. Не добавлять retries, HTTP, persistence или AgentRunner.

Пользователь согласовал durable recovery в этапе 20. Защита этапа 19 действует только внутри живой сессии; идентичность сохраняет incarnation/turn/step/output position, а не глобальный call_id.
