# Композиция контекста обращения

Этап 16 добавляет подготовку полного `ModelRequest` из инструкций агента, разрешённых вкладов приложения, актуального окна и последующей истории диалога, нового input и описаний инструментов.

Изменение ограничено Application, изолированными тестами и документацией. Транспорт, хранение, схема, tokenizer, подсчёт бюджета, compact, выполнение инструментов, оркестрация и поиск истории не изменяются. Соседние библиотеки остаются только источниками контрактов.

Нормативная область: [agent-runtime](../../specs/agent-runtime/spec.md). Причины и пример: [context](context.md).
