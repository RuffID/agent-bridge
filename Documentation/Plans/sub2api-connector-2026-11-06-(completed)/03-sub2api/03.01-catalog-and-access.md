Статус: **completed** в согласованном unknown-window режиме первой версии. T01 остаётся отдельной проверкой доказанного источника бюджета и не блокирует этот режим. Зависимости: 02.02.

## Конкретный результат

Sub2Api options, access resolver, ModelCatalog и ModelSettingsReader.

## Затрагиваемые части и объём

adapters/AgentBridge.Sub2Api/Configuration и Models; tests/AgentBridge.Sub2Api.Tests; existing ModelSelectionValidator и IIndividualModelKeySource.

Привязать отдельный Sub2Api section с обязательными base address, default model/effort, source mode, shared key по режиму и конечными timeout. Сохранить приоритет индивидуального ключа и отсутствие fallback при ошибке. Проецировать exact ID/effort/API-доступность existing manifest как объявления сервера. В явном согласованном ServerValidationWithUnknownWindow оставить budget=null и серверную проверку; прежние политики требуют доказанного окна. Статическая таблица и guessed defaults запрещены. Required binding не раскрывает значения.

## Проверки

Fake HTTP: Bearer содержит выбранный ключ sub2api; key source вызывается в scope и фиксируется на run. Каталог: empty/missing metadata, malformed schema, aliases, budget equality/overflow, unsupported effort, 401/403/429/5xx, timeout и cancellation. Секреты отсутствуют в snapshots, errors и логах.

## Критерии готовности

AgentSettingsService и runner получают прежние обязательные контракты. Прежние политики дают Unsupported при неизвестном окне. Явный разрешённый ServerValidationWithUnknownWindow сохраняет null и серверную проверку, не подменяя окно порогом. Sub2Api API key не путается с OpenAI upstream credential; T01 закрывается доказательством источника, не fixture.
