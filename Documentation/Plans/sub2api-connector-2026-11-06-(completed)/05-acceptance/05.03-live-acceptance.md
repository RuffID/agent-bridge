# 05.03. Контролируемая проверка sub2api

Статус: **completed** в согласованном объёме первой версии без compact. Тег развёрнутого сервера: `latest`, по подтверждению пользователя. Зависимости: 05.02.

[Этап](main.md) · [Главный план](../main.md)

## Конкретный результат

Фактическое подтверждение выбранного HTTP/SSE пути на sub2api с OAuth upstream.

## Затрагиваемые части и объём

Отдельно разрешённое тестовое окружение sub2api, выделенный ключ/группа/аккаунт, готовый connector и consumer; evidence плана.

До запуска согласовать точные команды, адрес, доступ, допустимые расходы и необходимые операции; секрет не хранить в плане/логах. Использовать выделенную OpenAI-группу с известным OAuth аккаунтом, иначе успех через API-key account не подтвердит нужный сценарий. Проверить каталог/бюджет, JSON/SSE, несколько turns/tools с полным контекстом и restart без нового compact. Зафиксировать ограничение длины диалога и явный Unsupported compact; успешный compact и закрытие T05 не входят в приёмку первой версии. Это не разрешение deployment, рабочего SQL или изменения sub2api.

## Проверки

Подтвердить отсутствие исходящего previous_response_id и корректный full-context replay, терминальные события и сохранённый результат. Тестовые tools без реальных бизнес-последствий; ключи/reasoning/payload не включать в evidence. Ошибку OAuth или превышение бюджета не обходить обрезанием, повтором или тихим переходом на API-key upstream либо WebSocket. Live compact→generation не запускается ради первой версии.

## Критерии готовности

Все обязательные сценарии подтверждены с указанием версии/режима сервера и безопасного evidence. При недоступном окружении — verification с конкретным недостающим сценарием. Только после этого синхронизировать принятые delta requirements в main и рассмотреть archive по отдельному разрешению.

## Фактический результат

Подготовлен отдельный [приёмочный executable](../../../../tests/AgentBridge.LiveAcceptance/AGENTS.md) над свежей PostgreSQL DLL/NuGet поставкой05.02. Используются app-owned configuration/identity/projector/probe исходники существующей консоли; соседний проект и его vendor не изменены. Первая фаза создаёт один новый тестовый диалог и выполняет JSON turn с единственным console_probe; вторая фаза отдельным процессом читает сохранённый диалог и отправляет SSE turn без повторного tool.

Пускатель проверяет полный canonical input, отсутствие previous_response_id, сохранённые отчёты/provenance/tool pair и неизменность первого turn после restart. Compact вызывается только через public gateway и должен вернуть Unsupported до HTTP. Эксклюзивный журнал резервирует отправки и tool до действия; лимит10 generation/2 manifest общий на обе фазы. Redirect, повтор одинакового запроса, maintenance/fence/recovery и автоматическое продолжение после ошибки отсутствуют. Evidence ограничен безопасными ID/хешами/счётчиками/проверками, без payload/reasoning/секретов.

При подготовке2026-11-08 выполнены локальные restore и compile-check:

```text
dotnet build tests/AgentBridge.LiveAcceptance/AgentBridge.LiveAcceptance.csproj -c Debug --no-restore -p:BaseOutputPath=D:\Media\User\source\repos\agent-bridge\artifacts\compile-check\live-acceptance\
```

Restore из локального кэша создал lock; сборка —0 ошибок/предупреждений. Затем пользователь разрешил обе точные команды и подтвердил тестовую PostgreSQL и OAuth-группу существующего ключа. Подключение использует local config консоли: endpoint `https://sonmp.ru:2457/`, модель `gpt-6.1-sol`, effort `medium`; секреты не публикуются.
