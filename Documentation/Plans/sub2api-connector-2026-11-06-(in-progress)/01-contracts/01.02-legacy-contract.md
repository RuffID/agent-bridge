## Конкретный результат

Список сохраняемых public contracts и воспроизводимый способ сравнения старого/нового подключения.

## Затрагиваемые части и объём

AgentBridge.Integration/AgentBridgeIntegrationExtensions.cs; CodexLb public options/extensions/classes; Application/Ports; tests/Delivery/Consumer и Metadata; current delivery manifests.

Зафиксировать старый AddAgentBridge и прямые AddCodexLb* вызовы, public constructors/types/assembly identity, config section CodexLb, индивидуальные ключи, TryAdd overrides, lifetimes и повторную регистрацию. Определить контрольный исходный consumer без бизнес-правок и baseline бинарный consumer для заявляемой ABI-совместимости. Не брать произвольные старые kits без provenance.

## Проверки

Сопоставить исходники и PE metadata доступного текущего комплекта. Отделить неизменность исходного API от ABI, runtime и wire-совместимости; baseline брать до рефакторинга и сохранять вне исходников.

## Критерии готовности

Известно, какие типы нельзя переносить/удалять без совместимого wrapper. Сохранены все функции codex-lb. Нет обещания убрать его DLL из legacy facade closure без доказательства.

## Фактический результат

Зафиксированы [legacy API, constructors, signatures, конфигурация и DI semantics](legacy-api-baseline.md), [методика и точные команды](compatibility-checks.md), [машинная опись evidence](baseline-evidence.json). Найден подходящий current SDK kit SqlServer/win-x64: все112 manifest entries проверены по size/SHA256, source/EF/HTTP fingerprints совпали с provenance. PE metadata шести собственных assemblies сопоставлена с исходниками; для CodexLb зафиксированы все13 public types, для ядра сохранены DLL/XML и PE опись169 top-level public types.

До transport/DI рефакторинга сохранены kit, manifests, оригинальный consumer, расширенный compile-only consumer и две скомпилированные frozen consumer DLL вне репозиториев: `C:\Users\Spike\AppData\Local\AgentBridge\CompatibilityBaselines\sub2api-2026-11-06`. Первоначальные127 сохранённых файлов повторно проверены по hashes. Сохранение подтверждает наличие исходного комплекта, а не успешную работу приложения с ним.

Добавлен только [LegacyTransportSurfaceProbe.cs](../../../../tests/Delivery/Consumer/LegacyTransportSurfaceProbe.cs). Существующие AddAgentBridge, AddCodexLb*, production source и настройки не менялись. Новой поставки ещё нет, поэтому old-binary→new-DLL ABI и фактическая серверная совместимость не подтверждены. Методика разделяет source rebuild, semantic PE/MemberRef comparison неперекомпилированных binaries, Windows runtime и live OAuth. CodexLb остаётся в closure facade; его удаление не разрешено.
