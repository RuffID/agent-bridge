# 01.01. Матрица протокола sub2api

Статус: **completed** (статическая фиксация контракта). Зависимости: Нет.

[Этап](main.md) · [Главный план](../main.md)

## Конкретный результат

Проверяемая матрица endpoint/request/response/capability для выбранного OpenAI-направления.

## Затрагиваемые части и объём

sub2api backend/internal/server/routes/gateway.go; handler/openai_gateway_handler.go, openai_codex_models_handler.go; service/openai_codex_models_service.go; AgentBridge.CodexLb/Responses и Models.

Разобрать Bearer-авторизацию, base-prefix без двойного /v1, обычный и Codex каталоги, JSON/SSE Responses, tool pairing, compact, ошибки и отмену. Зафиксировать происхождение бюджета/effort, зависимости от upstream OAuth/API key и отличие полного рабочего контекста от server anchor. Подготовить обезличенные wire fixtures с явным происхождением; синтетический пример не называть реальным ответом.

## Проверки

Статически пройти routes → handler → upstream transformation и сравнить обязательные поля с readers/writers AgentBridge. Проверить пустой/неполный каталог, неизвестную модель и неприменимость previous_response_id к выбранной стратегии.

## Критерии готовности

Каждая обязательная возможность связана с источником или конкретной остающейся проверкой T01/T02. Нет утверждения о live-совместимости без запуска. Нужное расширение соседней библиотеки явно выделено, обходной HTTP-клиент не планируется.

## Фактический результат

Подготовлены [матрица протокола](wire-matrix.md), [семь групп обезличенных образцов](wire-samples.md) и [SHA256 опись113 исходников](source-evidence.json). Прослежены routes → auth/handler → forwarding/transform, оба каталога, JSON/SSE, tool pairing, reasoning, compact, ошибки и disconnect. Каждый вывод привязан к owning source либо к конкретной последующей проверке.

Подтверждено ограничение HTTP previous_response_id для OpenAI OAuth/SetupToken upstream; выбран полный рабочий input без этого поля. Runtime этой стратегии не подтверждён. Найдено отсутствие достаточного публичного input budget contract: context_window/effective percent не превращаются в InputContextWindow. Выбор с неизвестным budget должен остаться Unsupported (T01). Max output из внутренних metadata не гарантированно публикуется в manifest; OAuth удаляет max_output_tokens. Отдельно выделены server-side retry/opaque normalization и compact model fallback (T05).

Выполнены только чтение, поиск и SHA256 источников; JSON образцов, ссылки, статусы и кодировка проверяются вместе с документами этапа. Live HTTP, Go-тесты, приложения и проектные scripts не запускались. Новый адаптер и shared Responses-код не созданы. T01/T02/T05 остаются обязательными для следующих этапов; completed означает готовность матрицы, не принятие коннектора.
