# 01. Контракты и совместимость

Статус: **completed** (контракты и baseline, без реализации коннектора). Зависимости: Нет.

## Цель

Зафиксировать проверяемый wire-контракт sub2api и границу совместимости до изменения runtime.

## Границы

Чтение текущих AgentBridge/sub2api, тестовые образцы без секретов и проектирование. Вызовы реального сервера и изменение соседних проектов не входят.

Общие требования и ограничения — в [главном плане](../main.md); нормативный проект — в [OpenSpec](../../../../openspec/changes/add-sub2api-connector/specs/agent-runtime/spec.md).

## Общий результат и приёмка

Проверяемая матрица endpoint/request/response/capability для выбранного OpenAI-направления. Список сохраняемых public contracts и воспроизводимый способ сравнения старого/нового подключения. Этап завершён только при выполнении критериев всех подэтапов и записи фактических проверок. Пропуски обязательной проверки сохраняют незавершённый статус.

## Фактический результат

Подготовлены [матрица](wire-matrix.md), [образцы](wire-samples.md), [исходный API/DI контракт](legacy-api-baseline.md), [воспроизводимые проверки](compatibility-checks.md), [source evidence](source-evidence.json) и [binary evidence](baseline-evidence.json). Статическая часть принята в объёме этапа: оставшиеся неизвестные имеют конкретные проверки, а не выдуманные значения.

Два внешних compile-only consumer собраны против сохранённой текущей поставки, оба без warnings/errors. PE читались без исполнения целевых DLL. Обязательные ограничения: нет подтверждённого публичного input budget, OAuth output limit не навязывается, server может менять/retry opaque/compact; это T01/T02/T05. Будущая ABI/runtime/live совместимость не проверена. Ссылки, solution items, JSON/XML и UTF-8 проверены статически; strict OpenSpec CLI не запускался.

Работа остановлена после01. Этап02 и реализация Sub2Api/DI/shared code не начаты; для продолжения требуется отдельное поручение.

Финальная статическая проверка: 29 Markdown-файлов, 211 относительных ссылок, 11 JSON-образцов и 3 SSE data-образца; 87 solution items, включая все 25 файлов плана. Сверены SHA256 для 113 исходников, 127 первоначально сохранённых файлов baseline, 6 контрольных бинарных материалов и 27 consumer sources; текущий probe совпадает с сохранённым. Ошибок не найдено. Эта проверка не исполняет consumers и не подтверждает совместимость с сервером.
