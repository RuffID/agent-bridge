## Конкретный результат

Проверенные core/CodexLb/Sub2Api/facade сценарии и согласованные OpenSpec artifacts.

## Затрагиваемые части и объём

Все затронутые concrete csproj, existing core/CodexLb/persistence/hosting suites, новый Sub2Api suite; OpenSpec change.

Провести статическую проверку build hooks и тестовых fixtures. При разрешённом запросе выполнить local restore, compile-check и isolated tests конкретных проектов; persistence фильтровать Dependency!=Database. Проверить обратную совместимость зарегистрированных custom ports, индивидуальные ключи и safe diagnostics. Сопоставить каждый сценарий delta spec первой версии с meaningful test/evidence, без helper-only замены public path. Для sub2api обязательны полный контекст через отдельный guard, отключённый automatic compact и Unsupported ручного/force compact до factory/HTTP; успешный compact и закрытие отложенного T05 не требуются. Сохранить регрессию прежнего compact codex-lb.

## Проверки

Counts passed/failed/skipped, ноль неожиданных предупреждений/ошибок, отсутствие live HTTP/SQL/Docker в isolated suites. Strict OpenSpec commands запускаются только с действующим разрешением; существующие warnings не выдаются за дефект новой реализации и не игнорируются при объявлении полной validation.

## Критерии готовности

Legacy и новый путь зелёные в объявленной isolated границе, regression failures устранены, strict validation result и оставшиеся ограничения записаны. Это не закрывает live05.03.

## Фактический результат

Не начато. Изменений кода и результатов выполнения нет. Перед выполнением сверить owning AGENTS, текущие исходники и разрешения; после записать фактические команды, результаты и ограничения, синхронизировать статус в навигаторах.
