## Общий результат и приёмка

До отправки различаются родной, legacy-неизвестный и чужой opaque-контекст. Existing AgentRunner проходит sub2api end-to-end path с durable ordering и pinned access/settings. Этап завершён только при выполнении критериев всех подэтапов и записи фактических проверок. Пропуски обязательной проверки сохраняют незавершённый статус.

## Фактический результат

Реализация не начата. Подготовлены только план и критерии; команды этого этапа не выполнялись.
