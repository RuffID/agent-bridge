# 04.01. Provenance и граница смены коннектора

Статус: **verification**. Зависимости: 03.03.01 в обязательном объёме первой версии этапа03; отложенный compact/T05 не требуются.

[Этап](main.md) · [Главный план](../main.md)

## Конкретный результат

До отправки различаются родной, неизвестный и чужой opaque-контекст. Старый JSON не поддерживается.

## Затрагиваемые части и объём

ModelContinuation, ContextModelGuard, adapter validation и stored response/compact metadata; persistence serializers только при доказанной необходимости.

Закрыть границу происхождения T03: хранить явную connector identity отдельно от canonical данных и transport continuation, не смешивать её с model ID. Проверять полное рабочее окно и непокрытые outputs, включая compact без continuation. Сохранение уже записанных старых диалогов не требуется. Использовать единственный новый JSON-формат без чтения v1 и ветвления v1/v2; несовместимый JSON отклонять явно без backfill. Чужой/неподтверждённый opaque state отклонять безопасно, историю не удалять. Не снимать guard только потому, что ID модели совпал. Не передавать внутреннюю identity в upstream payload.

## Проверки

Одинаковые модели у разных шлюзов, отсутствие identity в legacy rows, подмена endpoint/key, чужой continuation, compact-only окно, mixed tail, обычный текст и unknown format. Проверить отказ до HTTP и отсутствие изменения исходных данных.

## Критерии готовности

Нет скрытого cross-provider replay; текущие codex-lb generation/compact/continuation сохраняются для нового формата. Добавление отдельных metadata к публичным моделям и единственный новый формат согласованы; прежние публичные сигнатуры сохраняются. Миграция схемы БД не входит; при её необходимости требуется отдельное согласование.

## Фактический результат

Реализованы отдельные ModelConnectorProvenance/IModelContextGateway, проверка каждого opaque источника до Begin и HTTP, маркировка generation/compact/partial output и единственный новый persistence JSON wrapper. Старые публичные сигнатуры сохранены; JSON старых отчётов отклоняется без backfill. Физическая схема БД и отдельный budget snapshot v1/v2 не менялись.

Добавлены и адаптированы тесты ядра, Sub2Api, CodexLb и persistence. Compile-check девяти конкретных проектов прошёл без warnings/errors; тесты не запускались. Поведение guards/JSON/SSE и round-trip пока подтверждено только статически и компиляцией; 04.01 не completed. Команды и ограничения — в [результатах04](results.md). 04.02 не начат.
