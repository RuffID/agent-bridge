## Конкретный результат

Sub2Api IModelGateway.GenerateAsync для полного рабочего контекста без previous_response_id.

## Затрагиваемые части и объём

Sub2Api Responses gateway; общий protocol02.02; AgentRunner/ContextBuilder existing paths; Sub2Api isolated tests.

Передавать canonical items, instructions, tools, reasoning effort и поддержанные controls через HttpClientLibrary. Не отправлять codex-lb continuation/turn-state. Проверить необходимость/форму stream и получения финального JSON для non-stream API приложения по матрице01.01. Сохранить lifecycle, output ordering, terminal confirmation, encrypted reasoning и full canonical tool pairs. Existing diagnostics фиксирует безопасный итог внешней операции, без дублирования raw transport logs.

## Проверки

Несколько turns, несколько tools, повторные call_id в разных позициях, partial/error SSE, отсутствие terminal event, invalid JSON, unsupported controls, callback exception, dispose exception, caller/deadline. Полный контекст передаётся на каждом шаге; нет смешения с необоснованным server anchor и повторного выполнения инструмента при HTTP-отказе.

## Критерии готовности

Оба режима IModelGateway возвращают прежние ModelResponse/ModelStreamUpdate контракты. T02 подтверждён isolated fixtures в пределах их происхождения; фактическая OAuth-совместимость ещё не объявляется. Неудача не вызывает автоматический retry, смену модели/ключа/коннектора.

## Фактический результат

Разобраны обе actual forwarding ветки, включая non-stream: OAuth использует upstream stream=true, удаляет max_output_tokens; SSE-to-JSON может оставить SSE при отсутствии terminal. Обычная ветка может удалить encrypted reasoning и повторить запрос. Manifest/model echo и один HTTP-запрос AgentBridge не доказывают фактическую обработку сервера. [Evidence и условия продолжения](contract-blockers.md).

Sub2ApiModelGateway возвращает явный Unsupported до HTTP/factory/callback для JSON/SSE, в том числе при direct call/custom settings, opaque input и legacy continuation. Canonical payload не изменяется. Это защитная граница, а не реализация JSON/SSE транспорта. Общий framework и копия CodexLb gateway не создавались. T02/T05 не закрыты; provenance/restart04 не реализуются обходным путём.

[Проверки](results.md): blocked gateway/caller/immutability, прежние linked механизмы и полная isolated codex-lb regression. Actual Sub2Api JSON/SSE lifecycle, callbacks/partial/tools/no-replay и live OAuth цепочка не подтверждены и остаются обязательными после снятия блокировки.
