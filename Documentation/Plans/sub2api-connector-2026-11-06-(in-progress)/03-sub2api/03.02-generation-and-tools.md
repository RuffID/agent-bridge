# 03.02. JSON/SSE генерация и инструменты

Статус: **verification** (actual JSON/SSE проверены изолированно; live T02 открыт). Зависимости: 03.01.

[Этап](main.md) · [Главный план](../main.md)

## Конкретный результат

Sub2Api IModelGateway.GenerateAsync для полного рабочего контекста без previous_response_id.

## Затрагиваемые части и объём

Sub2Api Responses gateway; общий protocol02.02; AgentRunner/ContextBuilder existing paths; Sub2Api isolated tests.

Передавать canonical items, instructions, tools, reasoning effort и поддержанные controls через HttpClientLibrary. Не отправлять codex-lb continuation/turn-state. Проверить необходимость/форму stream и получения финального JSON для non-stream API приложения по матрице01.01. Сохранить lifecycle, output ordering, terminal confirmation, encrypted reasoning и full canonical tool pairs. Existing diagnostics фиксирует безопасный итог внешней операции, без дублирования raw transport logs.

## Проверки

Несколько turns, несколько tools, повторные call_id в разных позициях, partial/error SSE, отсутствие terminal event, invalid JSON, unsupported controls, callback exception, dispose exception, caller/deadline. Полный контекст передаётся на каждом шаге; нет смешения с необоснованным server anchor и повторного выполнения инструмента при HTTP-отказе.

## Критерии готовности

Оба режима IModelGateway возвращают прежние ModelResponse/ModelStreamUpdate контракты. T02 подтверждён isolated fixtures в пределах их происхождения; фактическая OAuth-совместимость ещё не объявляется. Неудача не вызывает автоматический retry, смену модели/ключа/коннектора.

## Фактический результат

[Принятая клиентская граница](client-adaptation.md): AgentBridge сохраняет полный canonical request на входе sub2api и полученные output/envelope; existing server reasoning normalization/recovery допустимы без обещания upstream сохранности. Response.model остаётся объявленным значением/requested echo. Server retries не равны client retries. sub2api не дорабатывается.

Реализован actual Sub2ApiModelGateway → HttpClientLibrary → один POST /v1/responses. Shared writer передаёт полный prepared context: compact-окно, непокрытый хвост/current input, reasoning, instructions, tools, effort/controls и call/output пары. Incoming continuation отклоняется до factory/HTTP/callback; returned response id/turn-state не создают anchor. Прямой gateway не выполняет бизнес-инструменты, не делает retries и не меняет ключ/модель/коннектор.

JSON/SSE выбираются по фактическому Content-Type, в том числе SSE вместо non-stream JSON. Shared SSE accumulator сохраняет canonical ordering/partial arguments/text/opaque и terminal confirmation; CodexLb wrapper сохраняет прежнюю continuation/error семантику. Callback последовательный и awaited, JSON fallback передаёт полные items. Caller/deadline различаются; partial output и explicit failure не теряются. Callback/read primary и cleanup failures сохраняют identity и secondary причины. Safe log outcome не считает HTTP200/EOF успехом.

[Проверки и команды](results.md):151 Sub2Api cases и414 CodexLb regression прошли, пять compile-check без warnings/errors. Public facade dispatch, несколько полных запросов с tool pair, non-stream SSE, output ordering/EOF, terminal/errors, callbacks, invalid UTF-8/JSON, caller/deadline, cleanup/ownership и безопасные логи подтверждены изолированно. Это не live OAuth/развёрнутый pool или интеграция recovery04. T02 live-приёмка остаётся на05; T05 compact не закрыт. Этап04 не начат.
