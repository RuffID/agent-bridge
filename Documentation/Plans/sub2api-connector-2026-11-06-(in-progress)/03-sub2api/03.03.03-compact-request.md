# 03.03.03. Запрос к existing compact endpoint

Статус: **not-started**. Зависимости: положительное подтверждение03.03.02; при текущем T05 не начинать.

Объём: отдельная отложенная работа вне обязательной первой версии. Возобновление требует нового достаточного основания и отдельного поручения.

[Этап03](main.md) · [Навигатор compact](03.03-compaction.md)

## Конкретный результат

Подготовка и один HTTP dispatch подтверждённого compact request через actual HttpClientLibrary, без активации полученного окна.

## Затрагиваемые части и объём

Sub2Api compact request writer/transport и адресные тесты. Использовать только existing POST /v1/responses/compact и подтверждённый body; не заменять генерацией, текстовым резюме или guessed flags. Сохранить canonical items, encrypted reasoning, instructions/effort, ordering и полные tool pairs. Неподдержанный запрос отклонять до factory/HTTP.

Использовать существующие access/timeout/caller/error/logging границы HttpClientLibrary. Один клиентский запрос, без retry, смены ключа/модели/коннектора и выполнения бизнес-инструментов. Логи содержат безопасный исход операции без ключей и содержимого; HTTP-успех не объявляется принятым окном. При реализации синхронизировать ближайшие AGENTS адаптера и тестов.

## Проверки и критерии готовности

Fake handler проверяет exact endpoint/body и canonical ordering, выбранный доступ, preflight до factory, caller/deadline, HTTP rejection и отсутствие повторов. Compile-check/изолированные tests допустимы только после проверки build chain по csharp-project-rules, с BuildProjectReferences=false; read-only библиотеки не пересобирать. AppData, внешний kit и frozen consumer не используются.

Результат ограничен транспортной заготовкой и её тестами: automatic compact остаётся отключённым, публичный compact не выдаёт успех до03.03.05. Чтение ответа относится к03.03.04, сохранение — к03.03.05.

## Фактический результат

Не реализован. Декомпозиция не разрешает обход T05 или возобновление реализации.
