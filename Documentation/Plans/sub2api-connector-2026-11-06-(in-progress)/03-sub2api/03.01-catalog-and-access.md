# 03.01. Настройки, ключ и каталог моделей

Статус: **blocked** (независимая реализация выполнена; запуск блокирует T01). Зависимости: 02.02.

[Этап](main.md) · [Главный план](../main.md)

## Конкретный результат

Sub2Api options, access resolver, ModelCatalog и ModelSettingsReader.

## Затрагиваемые части и объём

adapters/AgentBridge.Sub2Api/Configuration и Models; tests/AgentBridge.Sub2Api.Tests; existing ModelSelectionValidator и IIndividualModelKeySource.

Привязать отдельный Sub2Api section с обязательными base address, default model/effort, source mode, shared key по режиму и конечными timeout. Сохранить приоритет индивидуального ключа и отсутствие fallback при его ошибке. Преобразовать согласованный manifest в ModelCapabilities с точными model IDs/effort и доказанным input budget. Не вводить статическую таблицу возможностей для сокрытия неполного каталога. Required binding не раскрывает значения.

## Проверки

Fake HTTP: Bearer содержит выбранный ключ sub2api; key source вызывается в scope и фиксируется на run. Каталог: empty/missing metadata, malformed schema, aliases, budget equality/overflow, unsupported effort, 401/403/429/5xx, timeout и cancellation. Секреты отсутствуют в snapshots, errors и логах.

## Критерии готовности

AgentSettingsService и runner получают прежние контракты. Неподтверждённый бюджет даёт Unsupported. Sub2Api API key не путается с OpenAI upstream credential; T01 закрыт по результату.

## Фактический результат

В существующий bundle добавлены scoped access resolver, ordinary ModelCatalog и ModelSettingsReader. HttpClientLibrary использует app-owned HTTP/handlers/logger, per-request Bearer и bounded safe error pipeline. Только null individual допускает shared; ошибка/empty не дают fallback. ReadWithAccessAsync не вызывает источник повторно; primitive selection фиксируется до I/O. GenerationTimeout ограничивает send и body каталога, caller/cleanup причины сохраняются.

GET /v1/models без client_version подтверждает только ID. Metadata/effort/input budget не имеют достаточного публичного versioned provenance: все неподтверждённые значения остаются null/пустыми/false. Не выбирается выдуманная версия Codex manifest. Settings вызывает прежний ModelSelectionValidator и даёт Unsupported. Реализация не включает server admin API, guessed defaults или ослабление validator.

T01 повторно разобран по текущим исходникам0.2.19; его закрытие и пригодный settings path заблокированы. [Точное необходимое расширение](contract-blockers.md), [проверки и команды](results.md). Compile-check и isolated access/catalog/settings/URI/errors/cancellation/cleanup/log tests выполнены; успешный запуск и live OAuth не подтверждены.

В продолжении03 уточнено existing metadata intersection: availability failure может сузить каталог до schedulable subset, а descriptor defaults не маркируют provenance. Ordinary/passthrough используют различную цепочку mapping. Серверное предложение отклонено пользователем: sub2api не дорабатывается. [Текущая адаптация](contract-blockers.md) ищет достаточный источник в существующем контракте и отдельно отмечает клиентскую границу неизвестного бюджета. Existing ServerValidation не отменяет требование известного InputContextWindow. Settings/validator не изменялись, T01 открыт. Дополнительных тестовых прогонов в этом продолжении нет.
