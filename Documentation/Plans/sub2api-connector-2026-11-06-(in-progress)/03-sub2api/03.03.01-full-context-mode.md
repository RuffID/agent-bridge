# 03.03.01. Безопасный режим с полным контекстом

Статус: **completed в изолированных границах**. Зависимости: реализованный клиентский путь03.02; live T02 не требуется для этого результата.

[Этап03](main.md) · [Навигатор compact](03.03-compaction.md)

## Результат и границы

При отключённом automatic compact достижение локального threshold не останавливает generation. Полный PreparedRequest проходит отдельный budget guard; при отказе нет обрезания, client retry, смены выбора или повторного бизнес-инструмента. Ручной/force compact возвращает Unsupported до factory/HTTP. Совместимость opaque compact этим не подтверждается.

## Затронутые части

IModelGateway.AutomaticCompactionEnabled, ContextCompactor, ContextCompactionStatus, Sub2ApiModelGateway и Sub2ApiAutomaticCompactionTests. Default automatic прежних gateways сохранён. Проверки используют actual HttpClientLibrary с fake handler и in-memory storage; provenance/restart04 не входят.

## Проверки и критерии готовности

Полный canonical input с encrypted reasoning, instructions/effort, ordering и tool pair сохраняется выше threshold. Known overflow отклоняется guard до HTTP; unknown window не подменяется числом. Disabled не вызывает compact/save, force остаётся Unsupported. Серверный отказ не запускает повтор. Прежнее окно, terminal prefix, непокрытый хвост и история сохраняются.
