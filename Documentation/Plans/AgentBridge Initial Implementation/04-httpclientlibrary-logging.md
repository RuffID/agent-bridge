# 04 — Развитие контракта логирования HttpClientLibrary

Статус: **Не начат**. Зависимости: **00, 03**.

## Цель

Добавить в общую HTTP-библиотеку уже согласованное безопасное логирование по умолчанию.

## Задачи

- [ ] Согласовать точный контракт конфигурации и получить разрешение на правки соседней библиотеки.
- [ ] Реализовать логирование статуса и безопасных метаданных по умолчанию, а содержимого ответа — только по явной настройке.
- [ ] Сохранить статус ошибки и ограниченные диагностические данные без записи секретов в лог.
- [ ] Сохранить поведение JSON, потоковой выдачи, отмены и владения содержимым.
- [ ] Проверить соответствие исходного контракта версии DLL, используемой AgentBridge.

## Проверка и завершение

Выполнить разрешённые изолированные тесты с подставными HTTP-обработчиками и сохранением логов. Этап завершён, когда успешные, ошибочные и потоковые ответы соблюдают контракт без замены HTTP-слоя внутри AgentBridge.
