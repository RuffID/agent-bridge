# 19 — Выполнять разрешённые инструменты приложения

Статус: **Не начат**. Зависимости: **07, 14, 16**.

## Цель

Связать вызовы функций модели с зарегистрированными бизнес-обработчиками, явно определив владельца и ограничения выполнения.

## Задачи

- [ ] Регистрировать описания инструментов, схемы аргументов и обработчики приложения.
- [ ] Проверять идентификатор вызова, аргументы и разрешения приложения перед выполнением.
- [ ] Сохранять результаты, соответствующие вызовам функций, в последующих входных данных модели.
- [ ] Ограничить число шагов, сроки и параллельность выполнения, исключив использование одного контекста БД несколькими параллельными задачами.
- [ ] Сохранять информацию об ошибке инструмента без подмены успешным результатом.
- [ ] Предотвратить автоматическое повторное выполнение побочных действий после прерывания с неопределённым исходом.

## Проверка и завершение

Проверить сценарий диалога с GetOrderStatus, запрещённые и неизвестные инструменты, некорректные аргументы и частичный сбой. Этап завершён, когда последующий вопрос использует предыдущий контекст инструмента без раскрытия данных другого пользователя.
