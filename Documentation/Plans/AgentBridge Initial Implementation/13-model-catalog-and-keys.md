# 13 — Реализовать каталог моделей и выбор API-ключа

Статус: **Не начат**. Зависимости: **02, 04, 07**.

## Цель

Выбирать нужный ключ доступа и проверять параметры модели по возможностям codex-lb.

## Задачи

- [ ] Реализовать источник индивидуального и общего ключей, предоставляемый приложением.
- [ ] Использовать общий ключ только при отсутствии индивидуального, без переключения после ошибки его аутентификации.
- [ ] Получать `/v1/models` через HttpClientLibrary и сохранять необходимые метаданные возможностей моделей.
- [ ] Проверять выбранную модель, уровень усилия и бюджет входных данных без копирования статического каталога.
- [ ] Исключить ключи и конфиденциальные параметры подключения из возвращаемых снимков настроек и логов.

## Проверка и завершение

Проверить приоритет ключей, отсутствие ключей, неверный индивидуальный ключ и изменение возможностей моделей с помощью подставных HTTP-ответов. Этап завершён, когда отсутствует скрытая подмена ключа или модели.
