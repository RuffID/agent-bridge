# 23 — Проверить взаимодействие компонентов

Статус: **Не начат**. Зависимости: **12, 20, 21, 22**.

## Цель

Собрать содержательные подтверждения корректности границ библиотеки и соблюдения инвариантов при сбоях.

## Задачи

- [ ] Выполнить разрешённые адресные проверки компиляции и изолированные регрессионные тесты завершённых сценариев.
- [ ] Проверить канонические данные JSON/SSE/compact, непрерывность вызовов функций и обработку неполного завершения.
- [ ] Проверить приоритет ключей, изменение модели и усилия, нестандартный срок хранения и пороги токенов.
- [ ] Проверить отмену, гонки при очистке, восстановление после перезапуска и отсутствие повторных побочных действий инструментов.
- [ ] Получить отдельное разрешение для проверок с реальными SQLite/PostgreSQL, миграциями, бэкапами и работающим codex-lb.
- [ ] Зафиксировать проверенные версии зависимостей, пройденные проверки и непроверенное поведение провайдеров.

## Проверка и завершение

Этап завершён, когда необходимые подтверждения зафиксированы, а выявленные сбои устранены. Не объявлять интеграцию провайдеров проверенной только на основании подставных реализаций или локальной компиляции.
