# 16 — Сформировать контекст приложения и диалога

Статус: **Не начат**. Зависимости: **07, 14**.

## Цель

Формировать упорядоченные входные данные, которые будут переданы модели.

## Задачи

- [ ] Объединять инструкции агента, разрешённый контекст приложения, активное состояние контекста и последующие сообщения.
- [ ] Сохранять роли инструкций и полные пары вызовов функций и их результатов.
- [ ] Определить ответственность за провайдеры контекста, отмену и детерминированный порядок данных.
- [ ] Учитывать новое сообщение и необходимые описания инструментов при расчёте размера подготовленного запроса.
- [ ] Оставить поиск по старой истории за пределами реализации.

## Проверка и завершение

Проверить порядок контекста, изоляцию владельцев, сбой провайдера и продолжение со сжатым состоянием. Этап завершён, когда формирование контекста сохраняет системную роль текста и обязательное состояние протокола.
