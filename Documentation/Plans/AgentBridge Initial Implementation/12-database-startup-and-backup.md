# 12 — Явная инициализация БД и бэкап

Статус: **Не начат**. Зависимости: **05, 11**.

## Цель

Предоставить вызываемое приложением обслуживание по схеме AquaByte-Ledger через EFCoreLibrary.

## Задачи

- [ ] Реализовать проверку существующей БД, поиск неприменённых миграций, подтверждённый бэкап и порядок применения миграций.
- [ ] Реализовать явный путь первой установки без маскировки ошибок подключения.
- [ ] Обрабатывать пути и форматы бэкапа конкретного провайдера через согласованный контракт общей библиотеки.
- [ ] Проверить настройки бэкапа и согласовать срок его хранения до первого рабочего использования.
- [ ] Предотвратить параллельное обслуживание и коллизии имён файлов.
- [ ] Возвращать полезные результаты стадий и явно завершаться ошибкой при сбое обязательного бэкапа или миграции.

## Проверка и завершение

Заглушками обслуживания подтвердить порядок, отмену и обработку ошибок. Реальные бэкапы/миграции провайдера запускать только по явному разрешению. Этап завершён, когда загрузка DLL сама по себе не запускает обслуживание.
