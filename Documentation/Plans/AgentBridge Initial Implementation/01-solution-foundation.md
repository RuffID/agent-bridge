# 01 — Основа решения

Статус: **Не начат**. Зависимости: **00**.

## Цель

Создать границы SDK-style проектов .NET 10 для согласованной архитектуры библиотеки.

## Задачи

- [ ] Создать отдельные проекты ядра/прикладного слоя, адаптера codex-lb и хранения с явными направлениями зависимостей.
- [ ] Добавить проекты изолированных тестов вне каталогов исходников production-кода.
- [ ] Исключить зависимости ASP.NET Core, WPF и Telegram из переиспользуемого ядра.
- [ ] Настроить генерацию XML-документации, nullable-контракты и исключение каталогов результатов сборки.
- [ ] Добавить локальные `AGENTS.md` для архитектурных областей и обновить корневую карту проектов.
- [ ] Закрепить XML summary на русском и `<inheritdoc/>` для реализаций интерфейсов.

## Проверка и завершение

Перед разрешённой проверкой компиляции проверить ссылки проектов и хуки сборки. Этап завершён, когда сборки конкретных проектов соблюдают архитектуру без запуска приложения.
