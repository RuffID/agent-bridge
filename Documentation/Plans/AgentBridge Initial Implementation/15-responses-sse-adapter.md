# 15 — Реализовать потоковую передачу Responses через SSE

Статус: **Не начат**. Зависимости: **14**.

## Цель

Передавать результат по мере поступления, не принимая частичный текст за успешное завершение хода агента.

## Задачи

- [ ] Читать SSE через обёртку потокового ответа HttpClientLibrary.
- [ ] Разбирать многострочные данные событий, входные данные, поступающие фрагментами, и необходимые события жизненного цикла.
- [ ] Различать успешное завершение, ошибку, неполный результат и отмену.
- [ ] Сохранять состояние инструментов и непрозрачных выходных элементов вместе с текстовыми приращениями.
- [ ] Считать EOF без подтверждённого завершения незавершённым результатом.
- [ ] Освобождать потоки и обёртки ответов при любом способе выхода.

## Проверка и завершение

Проверить искусственные потоки с корректным завершением, ошибкой, преждевременным EOF, результатом только от инструментов и отменой. Этап завершён, когда вызывающая сторона получает явное итоговое состояние, а частичный результат не сохраняется как успешный.
