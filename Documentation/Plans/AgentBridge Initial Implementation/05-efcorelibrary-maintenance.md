# 05 — Развитие контракта обслуживания EFCoreLibrary

Статус: **Не начат**. Зависимости: **00**.

## Цель

Добавить в общую библиотеку возможности бэкапа и обслуживания БД с учётом провайдера.

## Задачи

- [ ] Согласовать с пользователем точные контракты обслуживания и бэкапа до изменения соседней библиотеки.
- [ ] Сохранить разделение технического обслуживания и базовых CRUD-репозиториев бизнес-данных.
- [ ] Определить обработку возможностей SQLite/PostgreSQL, результаты бэкапа, отмену и поведение ошибок.
- [ ] Сохранить порядок проверки, подтверждённого бэкапа и миграций существующей БД.
- [ ] Спроектировать первую установку отдельно от ошибок авторизации, прав и подключения.
- [ ] Не копировать в AgentBridge SQL Server-код бэкапа с прямым подключением.

## Проверка и завершение

Проверить контракты провайдеров и по возможности использовать изолированные заглушки. Реальные бэкапы и проверки БД требуют отдельного разрешения. Этап завершён, когда AgentBridge может использовать проверенный контракт EFCoreLibrary без внутреннего обхода библиотеки.
