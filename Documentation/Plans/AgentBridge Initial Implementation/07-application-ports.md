# 07 — Независимые контракты прикладного слоя

Статус: **Не начат**. Зависимости: **06**.

## Цель

Определить узкие контракты сценариев агента без утечки инфраструктурных типов.

## Задачи

- [ ] Определить контракты шлюза модели, поставщика контекста, обработчика инструментов и подсчёта токенов.
- [ ] Определить минимальные операции чтения диалога и контракты изменения данных конкретных сценариев.
- [ ] Определить результаты операций, различающие завершение, частичный результат, ошибку и отмену.
- [ ] Исключить `DbContext`, `IQueryable`, EF expressions и типы HTTP-библиотеки из прикладных контрактов.
- [ ] Документировать типы и методы интерфейсов на русском; в реализациях использовать `<inheritdoc/>`.

## Проверка и завершение

Сопоставить контракты со сценариями диалогов и инструментов. Этап завершён, когда реализации можно заменить изолированными заглушками без ссылок на инфраструктурные сборки.
