# 24 — Подготовить поставку DLL

Статус: **Не начат**. Зависимости: **23**.

## Цель

Подготовить полный комплект библиотек для подключения к приложениям .NET 10 через ссылки на бинарные файлы.

## Задачи

- [ ] Определить состав DLL ядра, адаптера codex-lb, выбранного хранилища и зависимостей времени выполнения.
- [ ] Включить совместимые EFCoreLibrary, HttpClientLibrary и зависимости токенизатора по необходимости.
- [ ] Включить сгенерированную XML-документацию, чтобы описания интерфейсов и `<inheritdoc/>` были доступны потребителям.
- [ ] Документировать выбор провайдера SQLite/PostgreSQL и необходимую конфигурацию без публикации в NuGet.
- [ ] Проверить, что потребитель может подключить комплект без путей к зависимостям относительно дерева исходного кода.

## Проверка и завершение

Проверить состав бинарных файлов и выполнить разрешённые проверки компиляции потребителя. Этап завершён, когда требования к зависимостям времени выполнения описаны явно, а сгенерированные DLL и выходные файлы не изменялись вручную.
