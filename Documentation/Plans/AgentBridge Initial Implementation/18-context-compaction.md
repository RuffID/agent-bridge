# 18 — Реализовать сжатие контекста с учётом версий

Статус: **Не начат**. Зависимости: **10, 14, 17**.

## Цель

Уменьшать рабочий контекст, сохраняя каноническое состояние внешнего сервиса и архивную историю.

## Задачи

- [ ] Вызывать `/v1/responses/compact` с полным необходимым контекстом.
- [ ] Сохранять новое каноническое окно контекста, непрозрачные элементы и охваченный диапазон истории.
- [ ] Активировать новый контекст только после успешного сохранения с проверкой актуальности версии.
- [ ] Соблюдать настраиваемый порог токенов и максимальное число проходов; прекращать сжатие, если размер не уменьшается.
- [ ] Сохранять предыдущий контекст при ошибке и не подменять compact скрытой генерацией обычного текстового резюме.
- [ ] Хранить исходную историю до настроенного срока истечения или явного удаления; мягкий порог байтов не запускает удаление архива.

## Проверка и завершение

Проверить непрозрачные результаты compact, повторное сжатие, отсутствие уменьшения, ошибку и потерю актуальности версии. Этап завершён, когда сжатие и хранение разделены, а неограниченный цикл сжатия невозможен.
