# 10 — Границы сценарных Unit of Work

Статус: **Не начат**. Зависимости: **09**.

## Цель

Обеспечить атомарность связанных изменений без глобального контейнера репозиториев.

## Задачи

- [ ] Определить минимальные Unit of Work изменяющих сценариев и общий технический scope сохранения/транзакций.
- [ ] Использовать один scoped-контекст EFCoreLibrary для участвующих репозиториев.
- [ ] Не связывать сценарии только чтения с ненужными UoW-контейнерами.
- [ ] Отделить ожидание внешней модели/инструмента от коротких транзакций БД.
- [ ] Проверять версию и доступность диалога перед сохранением итогового результата.

## Проверка и завершение

Проверить частичные ошибки и попытки сохранения неактуального диалога управляемыми заглушками. Этап завершён, когда связанные изменения имеют общую транзакционную границу, а параллельные задачи не используют один активный EF-контекст.
