# 08 — Модели хранения и контекст

Статус: **Не начат**. Зависимости: **05, 06, 07**.

## Цель

Настроить маппинг данных диалога через EF-контекст с выбираемым провайдером на основе EFCoreLibrary.

## Задачи

- [ ] Определить модели хранения диалогов, обращений, результатов инструментов и состояний контекста.
- [ ] Сохранить канонические данные протокола и стабильные поля последовательности/версии.
- [ ] Настроить владение, срок истечения, обязательные связи и индексы для реальных операций чтения.
- [ ] Зарегистрировать адаптер контекста и репозитории по актуальному контракту ключа контекста EFCoreLibrary.
- [ ] Добавить конфигурацию провайдера SQLite/PostgreSQL без обязательного выбора SQLite.
- [ ] Описать обязанности хранения в ближайшем `AGENTS.md`.

## Проверка и завершение

Статически проверить EF-модель и различия маппинга провайдеров. Этап завершён, когда маппинг сохраняет доменные инварианты, а сгенерированные миграции не редактируются вручную.

Источник: [интеграция EFCoreLibrary](<../../Technical documentation/02-efcorelibrary.md>).
