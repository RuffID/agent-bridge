# 09 — Адаптеры базовых репозиториев EFCoreLibrary

Статус: **Не начат**. Зависимости: **08**.

## Цель

Реализовать прикладные контракты данных через базовые операции общей библиотеки.

## Задачи

- [ ] Адаптировать чтение диалогов и контекста к базовым репозиториям по ID/условию.
- [ ] Использовать базовые репозитории создания, изменения и удаления для соответствующих операций.
- [ ] Сохранить стабильный порядок диалога и фильтры владения пользователем.
- [ ] Использовать custom query только тогда, когда нужная операция не выражается проверенными базовыми средствами.
- [ ] Обсуждать недостаточное или спорное поведение библиотеки с пользователем вместо прямого обхода через EF/SQL.

## Проверка и завершение

Проверить адаптеры изолированными заглушками репозиториев; реальные провайдеры проверять после разрешения. Этап завершён, когда общий CRUD делегируется библиотеке, а не копируется в AgentBridge.
