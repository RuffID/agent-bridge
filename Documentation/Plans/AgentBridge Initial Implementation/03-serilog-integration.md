# 03 — Подключение Serilog приложения

Статус: **Не начат**. Зависимости: **01, 02**.

## Цель

Направить диагностику библиотеки через Serilog приложения.

## Задачи

- [ ] Использовать `ILogger<T>` в компонентах библиотеки и описать регистрацию Serilog приложением.
- [ ] Определить полезные поля операции, корреляции, статуса и длительности.
- [ ] Передавать отмену вызывающего кода как отмену, а не как таймаут с уровнем ошибки.
- [ ] Исключить API-ключи, строки подключения и обычное содержимое диалогов из логов по умолчанию.
- [ ] Не создавать глобальный logger и не выбирать файловые sinks внутри библиотеки.

## Проверка и завершение

Использовать тестовый logger, сохраняющий события, для проверки структуры записей и отсутствия секретов. Этап завершён, когда регистрация библиотеки сохраняет конфигурацию логирования приложения.
