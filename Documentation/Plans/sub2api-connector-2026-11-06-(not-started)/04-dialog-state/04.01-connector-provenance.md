# 04.01. Provenance и граница смены коннектора

Статус: **not-started**. Зависимости: 03.03.

[Этап](main.md) · [Главный план](../main.md)

## Конкретный результат

До отправки различаются родной, legacy-неизвестный и чужой opaque-контекст.

## Затрагиваемые части и объём

ModelContinuation, ContextModelGuard, adapter validation и stored response/compact metadata; persistence serializers только при доказанной необходимости.

Закрыть T03: хранить versioned connector identity в подходящих существующих metadata, не смешивать её с model ID. Проверять полное рабочее окно и непокрытые outputs, включая compact без continuation. Legacy codex-lb state должен продолжаться через прежний путь без массового backfill. Чужой/неподтверждённый opaque state отклонять безопасно, историю не удалять. Не снимать guard только потому, что ID модели совпал. Не передавать внутреннюю identity в upstream payload.

## Проверки

Одинаковые модели у разных шлюзов, отсутствие identity в legacy rows, подмена endpoint/key, чужой continuation, compact-only окно, mixed tail, обычный текст и unknown format. Проверить отказ до HTTP и отсутствие изменения исходных данных.

## Критерии готовности

Нет скрытого cross-provider replay и регрессии codex-lb legacy history. Если metadata недостаточно и требуется schema/public contract change, подэтап остаётся blocked с конкретным предложением на согласование.

## Фактический результат

Не начато. Изменений кода и результатов выполнения нет. Перед выполнением сверить owning AGENTS, текущие исходники и разрешения; после записать фактические команды, результаты и ограничения, синхронизировать статус в навигаторах.
