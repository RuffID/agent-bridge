# Ошибки, отмена, частичные результаты и восстановление

Текст на экране, результат модели и подтверждённое сохранение — разные сведения. Приложение должно объяснять пользователю итог по всем трём, не выдавая предварительный текст за законченный ответ.

| Ситуация | Что это означает |
| --- | --- |
| Ответ завершён и сохранение подтверждено | Обращение успешно закончено |
| Поток оборвался после части текста | Известная часть остаётся частичным результатом |
| Нет доступа, срок истёк, версия устарела или модель не поддержана | Явный отказ; скрытой замены ключа/модели и повтора нет |
| Пользователь отменил обращение | Дальнейшая работа останавливается с сохранением известных результатов, насколько это допускает состояние хранения |
| Действие начато, итог не подтверждён | Исход неизвестен; нельзя говорить «ничего не произошло» |
| Ответ получен, но запись не подтверждена | Нельзя обещать, что диалог успешно сохранён |

Пример: после просьбы отменить заказ пользователь нажал «Стоп». Если бизнес-сервис уже выполнил отмену, остановка разговора не возвращает заказ в прежнее состояние.

## Поздняя отмена

Отмена может прийти после успешного сохранения. Тогда библиотека сообщает отмену вызывающей стороне и отдельно сохраняет факт принятого результата. Приложение не должно повторять действие только потому, что увидело статус отмены.

Неожиданные технические исключения могут передаваться приложению. Оно отвечает за безопасное сообщение и диагностику без ключей, подключений и полного содержимого запросов.

## После перезапуска

Доступная сохранённая история читается заново, но уже существующее обращение не исполняется автоматически. Начатое действие без подтверждённого исхода не повторяется.

Если в истории известен вызов инструмента без результата, следующий запрос блокируется. Библиотека не удаляет такой вызов и не придумывает ответ, чтобы продолжить диалог.

Приложение должно выяснить фактический исход действия в бизнес-системе и определить дальнейший разрешённый сценарий. Автоматический replay или универсальный механизм восстановления неизвестных действий не предоставляется.

При конфликте версий нельзя незаметно подставить свежую версию к старому результату. При истечении или удалении поздняя запись отклоняется; история не восстанавливается.
