# Назначение и границы

AgentBridge — библиотека для приложений на C# и .NET 10. Она подключается DLL и помогает организовать разговор пользователя с ИИ: собрать нужные сведения, обратиться к модели, выполнить разрешённые инструменты и сохранить диалог.

Один и тот же механизм можно использовать на сайте, в настольном приложении или боте. Экран чата, кнопки, вход пользователя и бизнес-процессы создаёт подключающее приложение.

## Кто за что отвечает

| Участник | Его задача |
| --- | --- |
| Приложение | Узнать пользователя, проверить права, предоставить бизнес-данные и обработчики действий, показать результат |
| AgentBridge | Вести состояние диалога, собирать контекст, координировать модель и инструменты, сохранять результаты |
| codex-lb | Проверять доступ к серверу и направлять запрос к upstream-модели |
| Выбранное хранилище | Сохранять данные между запусками; приложение настраивает SQLite либо PostgreSQL |

Например, AgentBridge может помочь ответить «Где мой заказ?». Право видеть заказ и фактический статус доставки определяет приложение. Модель не становится источником достоверных сведений о заказе.

## Границы возможностей

Библиотека не создаёт интерфейс и не запускает приложение, обслуживание БД или расписание очистки сама. Она не предоставляет поиск по старой истории после сжатия и не выбирает права пользователя.

Сохранённый диалог можно продолжить после перезапуска, если срок не истёк и состояние пригодно для следующего запроса. Это не означает автоматическое возобновление прерванных бизнес-действий.

В текущем коде есть полный ход агента, транспорт, хранение, сжатие, инструменты, настройки и очистка. Подробности подтверждения — [карта прежних проверок](<../Plans/AgentBridge Initial Implementation/25-usage-guide-and-closure.md>). Работа с живым сервером и загрузка DLL в конкретном приложении не подтверждаются одним наличием реализации.
