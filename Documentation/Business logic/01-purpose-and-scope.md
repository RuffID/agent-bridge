# Назначение и границы

## Продукт

AgentBridge позволяет добавить ИИ-агента в приложение на C# и .NET 10. Имя папки, проекта и будущего GitHub-репозитория — `agent-bridge`. Библиотека подключается обычными DLL.

Основные потребители: ASP.NET Core-приложение, сайт, WPF-приложение, Telegram-бот. Общая логика агента не привязана к одному виду интерфейса.

## Ответственность участников

| Участник | Ответственность |
| --- | --- |
| Подключающее приложение | Идентификация пользователя, права, бизнес-данные, инструменты, интерфейс и конфигурация |
| AgentBridge | Ведение диалога, сборка контекста, обращение к модели, координация инструментов, сохранение памяти |
| Адаптер codex-lb | Преобразование запросов и результатов в протокол codex-lb |
| codex-lb | Upstream-авторизация, выбор аккаунта, маршрутизация, передача результата модели |
| Настроенная БД | Сохранение истории и состояния диалогов между запусками приложения |

AgentBridge — разрабатываемая библиотека. Приложение сохраняет владение своей бизнес-логикой и определяет, что доступно агенту.

## Текущий объём

- Диалоги с сохранением контекста.
- Источники контекста и инструменты, зарегистрированные приложением.
- Отдельный адаптер codex-lb.
- Опциональный выбор SQLite или PostgreSQL через конфигурацию.
- Сжатие рабочего контекста по числу токенов.
- Мягкий порог объёма содержимого на диалог и срок хранения от создания.
- Чтение безопасных настроек, выбор модели/effort и дата истечения для интерфейса.
- Обслуживание БД, резервное копирование перед миграциями и очистка через EFCoreLibrary.

Поиск по старым сообщениям не входит в текущую версию. Полная история не подключается обратно через поиск после сжатия.

На данном этапе составляется документация. Перенос кода из других проектов и реализация библиотеки относятся к последующему этапу.

Источник требований: [agent-runtime](../../openspec/specs/agent-runtime/spec.md).
