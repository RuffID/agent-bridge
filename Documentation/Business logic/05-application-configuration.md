# Настройки подключающего приложения

Конфигурацией управляет приложение, подключившее AgentBridge. Приложение может использовать свой обычный механизм настроек; библиотека не привязывает работу к единственному файлу или к ASP.NET Core-хосту.

| Группа | Настройки |
| --- | --- |
| codex-lb | Адрес сервера, общий API-ключ и источник пользовательского ключа, выбранная модель, reasoning effort, время ожидания операций |
| Агент | Инструкции, доступные источники контекста, зарегистрированные инструменты |
| БД | Провайдер SQLite/PostgreSQL и параметры подключения |
| Резервные копии | Абсолютный каталог, явный положительный срок хранения без default; для PostgreSQL — абсолютный pg_dump path, major 10+ и конечный cleanup timeout |
| Хранение | Мягкий порог объёма содержимого на диалог и срок хранения от создания |
| Контекст | Порог сжатия в токенах |
| Выполнение | Ограничения времени и числа шагов инструментов |
| Диагностика | Serilog; безопасные метаданные по умолчанию, opt-in JsonStructure ошибки без исходных имён и значений; текст body не логируется |

Порог сжатия должен изменяться через конфигурацию. Конкретные значения параметров не зашиваются в бизнес-логику.

Регистрация обработчиков инструментов и источников контекста выполняется приложением программно. Настройка имени инструмента не предоставляет ему дополнительные права.

API-ключи и строки подключения относятся к секретам приложения. Они не включаются в контекст агента или обычные диагностические сообщения.

## Начальные значения

Пробные значения предназначены для первых внедрений и переопределяются конфигурацией приложения.

| Параметр | Начальное значение |
| --- | --- |
| Срок хранения от создания диалога | 7 дней |
| Мягкий порог содержимого на диалог | 10 МиБ (`10 485 760` байт) |
| Порог сжатия рабочего контекста | 32 000 токенов |
| Запас входного бюджета сверх подготовленного контекста | 4 096 токенов |
| Максимум последовательных проходов сжатия на одно обращение | 3 |
| Максимум шагов инструментов на одно обращение | 8 |
| Время ожидания генерации | 180 секунд |
| Время ожидания compact | 180 секунд |
| Reasoning effort | `medium`, если поддержан выбранной моделью и доступен ключу |

Модель берётся из конфигурации и проверяется по каталогу codex-lb. Неподдержанное имя модели или effort не заменяется незаметно другим значением.

Порог сжатия и запас должны укладываться в входной бюджет выбранной модели. Пробные значения не являются обещанием одинакового бюджета у всех моделей.

## Ключи

Если у пользователя задан индивидуальный ключ codex-lb, используется он. Если ключ отсутствует, применяется общий ключ приложения. Ошибка заданного индивидуального ключа не считается его отсутствием и не запускает скрытую повторную отправку с общим ключом.

## Чтение и изменение настроек

Библиотека предоставляет безопасное представление текущих настроек и позволяет выбрать другую модель и effort конкретного диалога. Defaults принадлежат приложению; сохранённый выбор в БД диалога имеет приоритет над ними, override запроса — над выбором. Активный ход сохраняет свой снимок; параллельное изменение версии даёт Conflict без повтора. Ключи и строки подключения не возвращаются и не сохраняются в выборе.
