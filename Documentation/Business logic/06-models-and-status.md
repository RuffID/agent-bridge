# Модели, effort, ключи и состояние диалога

Модель определяет, какой ИИ обрабатывает запрос. Effort — поддерживаемый моделью уровень усилия при подготовке ответа. Он не гарантирует конкретную точность или время ответа.

## Выбор модели

Приложение получает доступные модели и уровни effort из каталога codex-lb для выбранного ключа. Неподдержанное имя или effort не заменяется незаметно другим значением.

Для обращения применяется следующий приоритет:

1. Явный выбор только для этого обращения.
2. Сохранённый выбор диалога.
3. Начальные настройки приложения.

Разовый выбор не меняет сохранённый. Уже начавшееся обращение продолжает использовать свой снимок настроек. Если пользователь сохраняет новый выбор параллельно с другим изменением, устаревшая версия отклоняется без автоматического повтора.

Пример: смена модели во время ответа влияет на последующее обращение. Она не переключает модель посреди уже выполняющегося хода.

## Ключ доступа

Индивидуальный ключ пользователя имеет приоритет. Общий ключ применяется только при отсутствии индивидуального. Пустой, неверный ключ или ошибка его получения не считаются отсутствием: приложение получает отказ без скрытой попытки с общим ключом.

Ключи не входят в безопасное описание настроек и не сохраняются как выбор модели диалога.

## Совместимость контекста

Другая модель может не понимать непрозрачное состояние предыдущей. В таких случаях требуется обоснованное подтверждение совместимости со стороны приложения; без него смена отклоняется и история сохраняется. Даже подтверждённая совместимость не доказывает допустимый размер запроса.

Выбранное имя и модель, указанная сервером в ответе, могут отличаться. Интерфейс должен различать эти сведения. Встроенный счётчик поддерживает ограниченный набор имён; каталог не гарантирует поддержку tokenizer.

## Что можно показать пользователю

Дата создания и истечения, признак истечения, объём содержимого, число сжатий, выбранная модель/effort, модель последнего ответа при наличии и оценка сохранённого контекста доступны через статус.

Оценка статуса не включает будущий вопрос, инструкции, новые данные приложения и инструменты. Она не гарантирует, что следующий полный запрос поместится. Неизвестный размер показывается как неизвестный, а не как ноль.
