# Бизнес-логика AgentBridge

AgentBridge помогает приложению вести диалог с моделью, получать разрешённые бизнес-данные и выполнять доступные пользователю действия.

Это описание для человека, который решает, как будет работать продукт. Настройка DLL, API и примеры кода находятся в [техническом руководстве](<../Technical documentation/25-usage-guide.md>).

## Как читать правила

Согласованные требования находятся в [OpenSpec](../../openspec/specs/agent-runtime/spec.md). Эти страницы объясняют их, но не вводят новую политику. Текущая реализация прочитана выборочно для подготовки описания; это не полный аудит.

Первоначальная реализация 00–25 завершена в документированных границах: это подтверждают текущие файлы, локальная история до c8da604 и [отчёт 25](<../Plans/AgentBridge Initial Implementation/25-usage-guide-and-closure.md>). Старые упоминания будущих этапов не являются текущим статусом.

Исторические проверки не обещают работу с любым живым сервером, моделью и приложением. Неизвестный размер непрозрачного контекста, внешние действия и восстановление описаны с ограничениями. В отчётах OpenSpec CLI отсутствовал, validation не выполнялась; сейчас повторной проверки нет, changes не архивированы.

[Новый аудит](<../Plans/AgentBridge Quality Audit/README.md>) пока не начат. [Реестр расхождений и подозрений](<../Plans/AgentBridge Quality Audit/Findings.md>) сохраняет доказательства и открытые вопросы; противоречия не разрешаются переписыванием требований.
