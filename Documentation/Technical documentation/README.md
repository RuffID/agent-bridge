# Техническая документация AgentBridge

Документы описывают принятые границы, фактические API конфигурации, диагностики, доменного состояния и прикладных портов, проектируемую реализацию следующих областей. Этапы 00–06 приняты; этап 07 реализован и принят; запрещённые проверки пропущены (93 теста ядра, 27 новых); этапы 08–25 не начаты. Запрещённые проверки пропущены. Проверки этапов 02–06 находятся в соответствующих планах. Сценарии агента, HTTP-адаптер и EF-хранилище AgentBridge ещё не реализованы; названия их будущих типов обозначают обязанности.
