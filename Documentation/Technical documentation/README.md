# Техническая документация AgentBridge

Документы описывают принятые границы, фактические API конфигурации, диагностики и доменного состояния, проектируемую реализацию следующих областей. Этапы 00–03 завершены и приняты; этап 04 завершён и принят, запрещённые проверки пропущены; этап 05 реализован и принят, запрещённые проверки пропущены (89 изолированных тестов); этап 06 реализован и принят, запрещённые проверки пропущены (66 тестов ядра, 30 новых); этапы 07–25 не начаты. На этапе 02 все шесть проектов прошли compile-check и 47 тестов конфигурации; на этапе 03 проверены затронутые ядро и его тестовый проект, прошли 36 тестов ядра, включая 18 новых проверок диагностики. На этапе 04 прошли по 44 теста библиотеки на net8/net10, проверены DLL и transport error contract. Сценарии агента, HTTP-адаптер и EF-хранилище AgentBridge ещё не реализованы; названия их будущих типов обозначают обязанности.
