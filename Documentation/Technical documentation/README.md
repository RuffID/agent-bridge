# Техническая документация AgentBridge

Документы описывают принятые границы, фактические API конфигурации и диагностики, проектируемую реализацию следующих областей. Этапы 00–03 завершены и приняты; этапы 04–25 не начаты. На этапе 02 все шесть проектов прошли compile-check и 47 тестов конфигурации; на этапе 03 проверены затронутые ядро и его тестовый проект, прошли 36 тестов ядра, включая 18 новых проверок диагностики. Сценарии агента, HTTP и EF-хранилище ещё не реализованы; названия их будущих типов обозначают обязанности.
