# Стандартная интеграция

- SDK library net10.0 собирает ядро, CodexLb, Sub2Api и EF adapters. Обратные зависимости из ядра запрещены; ASP.NET Core/host не требуется.
- Конкретные провайдеры не входят в facade dependencies. Приложение явно регистрирует AddAgentBridgePostgreSql до фасада; Database.Provider выбирает ровно один подключённый модуль. При переносе descriptors IValidateOptions сохраняются через TryAddEnumerable, чтобы не потерять required/module validators.
- AddAgentBridgeSub2ApiAuxiliary — отдельный opt-in после выбора Sub2Api, без CodexLb registration/новых settings/HTTP при регистрации и resolve gateway. Прямой известный CodexLb auxiliary несовместим с Sub2Api; custom port сохраняется. Usage возвращает direct JSON, Images — завершённый JSON generation/multipart edits; upload Unsupported до HTTP factory.
- `AddAgentBridge(configuration, httpClientFactory)` принимает root/выбранный раздел с AgentBridge, Database и выбранным transport section. Default остаётся CodexLb. AddAgentBridgeSub2ApiConnector/AddAgentBridgeCodexLbConnector явно выбирают один bundle до facade; повтор того же выбора идемпотентен, иной выбор, включая смену default после facade, отклоняется без I/O. Фабричные custom ports сохраняются как app overrides; известные прямые CodexLb порты несовместимы с выбором Sub2Api и отклоняются перед facade. Direct AddCodexLb* не являются selector API и сохраняют прежнюю добавляющую семантику.
- Sub2Api binding не требует CodexLb. Existing bundle регистрирует actual access/catalog/settings через ту же app HTTP factory и HttpClientLibrary; gateway отдельно возвращает Unsupported до доказанного профиля T05. Каталог ID не подтверждает входной бюджет T01, поэтому settings не разрешает запуск. Options проходят safe binding/validation; IConfiguration не становится runtime dependency.
- Optional AgentBridge:Tokenization:ModelEncodings проходит core configuration/validator до startup I/O. Facade принимает exact дополнения к builtin mapping без новых transport/DB зависимостей; singleton counter фиксирует карту, изменение требует перезапуска. Custom IContextTokenCounter сохраняется.
- Приложение заранее регистрирует ILoggerFactory и optional индивидуальный источник. HTTP callback обязателен, scoped и без I/O при создании; приложение владеет HttpClient/handlers/timeout/disposal. Pipeline — actual AddCodexLbResponses/HttpClientLibrary, не собственный HTTP.
- Shared без app source использует внутренний null source; Individual без заранее зарегистрированного app source отклоняется options validation. Ошибки источника не меняют ключ.
- Existing contracts сохраняются через TryAdd при переносе module descriptors. Ordered IContextProvider перечисляются без сортировки внутри scoped ContextBuilder; custom ContextBuilder сохраняется. Tools/validators остаются scoped по existing tool registration.
- Повтор с теми же config/factory references — no-op; другие аргументы требуют нового ServiceCollection и явно отклоняются. Не создавать промежуточный ServiceProvider.
- DI не выполняет startup/maintenance/миграции/cleanup/compact/HTTP, не создаёт logger/files/auth/endpoints/scheduler. AddAgentBridgeDiagnostics вызывается только после проверки app logger factory.
- Проверки public composition находятся в existing persistence tests, только Dependency!=Database; actual EF metadata без подключения, fake handler/local streams без сети. Compile конкретного проекта с GeneratePackageOnBuild=false; kits/runtime относятся к15–19.
