# Адаптер sub2api

- Отдельная net10.0 библиотека зависит только от ядра и HttpClientLibrary. CodexLb, EF и hosting dependencies запрещены. Общие внутренние механизмы Responses подключены source link из соседней AgentBridge.Responses.
- Существующий bundle содержит scoped access resolver, ordinary ModelCatalog и ModelSettingsReader. Sub2ApiModelGateway ограждает generation/compact явным Unsupported до доказанного server profile T05; прямой вызов gateway/custom settings не обходят отказ до HTTP. Не включать транспорт по одной успешной fixture или guessed metadata.
- Публичный выбор — Integration.AddAgentBridgeSub2ApiConnector до старого AddAgentBridge. Bind получает section Sub2Api, не CodexLb. IConfiguration не передаётся runtime-компонентам. Секреты/значения неисправных options не включаются в ошибки.
- Приложение владеет ключевым источником, HttpClient/handlers/logger; регистрация не вызывает factory и не строит ServiceProvider. Individual source регистрируется заранее; error/empty индивидуального ключа не разрешает shared fallback.
- Каталог использует actual HttpClientLibrary, per-request Bearer, error capture 65536 bytes и safe ILogger pipeline без raw bodies/headers. GenerationTimeout ограничивает send и чтение каталога; caller cancellation приоритетнее deadline. Не скрывать primary/cleanup failures и не добавлять retry/общий кеш. Сам HttpApiClient не владеет borrowed HttpClient.
- BaseAddress принимает server/prefix или один завершающий /v1. Не угадывать полный endpoint/backend-api alias, двойной /v1 и encoded route. Legacy URL codex-lb не менять.
- Ordinary /v1/models без client_version подтверждает только точные ID. HasMetadata=false, budgets=null, efforts/modalities пусты, флаги false означают отсутствие подтверждения. Даже похожий metadata.input_context_window не является согласованным versioned контрактом sub2api. Settings сохраняет exact selection/pinned access и прежний validator; неизвестный бюджет даёт Unsupported. Условия расширения — contract-blockers.md этапа03.
- Будущий разрешённый Responses transport должен передавать полный рабочий контекст без previous_response_id/legacy turn-state. Provenance/persistence/restart принадлежат этапу04 и здесь не реализуются. T01/T02/T05 открыты; green tests не означают пригодность к генерации/live OAuth.
