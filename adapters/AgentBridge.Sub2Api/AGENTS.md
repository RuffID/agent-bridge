# Адаптер sub2api

- Отдельная net10.0 библиотека зависит только от ядра и HttpClientLibrary. CodexLb, EF и hosting dependencies запрещены. Общие внутренние механизмы Responses подключены source link из соседней AgentBridge.Responses.
- Существующий bundle содержит scoped access resolver, ordinary/declared manifest ModelCatalog/SettingsReader и actual JSON/SSE generation. Gateway отклоняет incoming continuation до factory; AutomaticCompactionEnabled=false не даёт локальному threshold остановить полный запрос из-за compact. Separate full budget guard обязателен; ручной/force compact Unsupported до factory/HTTP. Границы Responses — Responses/AGENTS.md; нет guessed enable flag.
- Публичный выбор — Integration.AddAgentBridgeSub2ApiConnector до старого AddAgentBridge. Bind получает section Sub2Api, не CodexLb. IConfiguration не передаётся runtime-компонентам. Секреты/значения неисправных options не включаются в ошибки.
- Приложение владеет ключевым источником, HttpClient/handlers/logger; регистрация не вызывает factory и не строит ServiceProvider. Individual source регистрируется заранее; error/empty индивидуального ключа не разрешает shared fallback.
- Каталог использует actual HttpClientLibrary, per-request Bearer, error capture 65536 bytes и safe ILogger pipeline без raw bodies/headers. GenerationTimeout ограничивает send и чтение каталога; caller cancellation приоритетнее deadline. Не скрывать primary/cleanup failures и не добавлять retry/общий кеш. Сам HttpApiClient не владеет borrowed HttpClient.
- BaseAddress принимает server/prefix или один завершающий /v1. Не угадывать полный endpoint/backend-api alias, двойной /v1 и encoded route. Legacy URL codex-lb не менять.
- Ordinary /v1/models без client_version подтверждает exact IDs, unknown capabilities и budget не подменяются. Явный Compaction.BudgetPolicy=ServerValidationWithUnknownWindow читает existing manifest с настоящей assembly version AgentBridge, проецирует объявленные slug/effort/API-доступность, сохраняя null окно и отсутствие provenance pool. Default strict/ServerValidation и ordinary settings Unsupported сохранены; подробности Models/AGENTS.md.
- sub2api не дорабатывается; адаптируется только AgentBridge к существующему серверу. [Серверное предложение](../../Documentation/Plans/sub2api-connector-2026-11-06-(in-progress)/03-sub2api/server-contract-proposal.md) отклонено. No-client-retry не запрещает все server retries. Принята canonical гарантия на входе sub2api и в истории AgentBridge с допуском existing server reasoning normalization/recovery; upstream сохранность не обещать. Не вводить обязательные новые headers/metadata; requested echo не подтверждает actual model. Mapping не доказывает несовместимость; actual identity не является отдельным условием. [T05](../../Documentation/Plans/sub2api-connector-2026-11-06-(in-progress)/03-sub2api/03.03-compaction.md) относится к пригодности compact-окна: recovery может удалить compaction целиком, когда покрытая история уже отсутствует в input. Best-effort активация такого окна не разрешена.
- Responses transport передаёт полный рабочий контекст без previous_response_id/legacy turn-state. Provenance/persistence/restart принадлежат этапу04 и здесь не реализуются. T01/T02/T05 открыты; isolated generation tests не подтверждают live OAuth или deployed pool.
